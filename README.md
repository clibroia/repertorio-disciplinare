# Repertorio disciplinare — I.S.I.S. Archimede

Repertorio digitale di richiami preventivi, note disciplinari e comunicazioni scolastiche, con riferimenti regolamentari e testi personalizzabili. Accessibile da desktop e mobile.

## Funzioni

- 42 formulazioni suddivise in 12 categorie.
- Ricerca per parola chiave e filtri per categoria e tipologia.
- Schede espandibili, testi modificabili e copia negli appunti.
- Interfaccia responsive e navigazione accessibile da tastiera.
- Nessun backend, account, tracciamento o salvataggio di dati personali.

## Avvio locale

Scaricare i file nella stessa cartella e aprire `index.html` nel browser. Per una migliore compatibilità della funzione Copia è consigliato utilizzare il sito pubblicato via HTTPS.

## Pubblicazione su GitHub Pages

1. Creare un repository pubblico, ad esempio `repertorio-disciplinare`.
2. Caricare nella radice `index.html`, `style.css`, `script.js` e `README.md`.
3. Aprire **Settings → Pages → Build and deployment**.
4. Selezionare **Deploy from a branch**, branch `main`, cartella `/(root)` e salvare.
5. Attendere la pubblicazione e utilizzare l'indirizzo mostrato nella sezione Pages.

**Nota:** GitHub Pages è pubblico. Non inserire dati personali, nomi di studenti o casi identificabili nel codice o nei contenuti del repository.

## Uso responsabile

Le formulazioni sono modelli da adattare a fatti accertati. La scelta del provvedimento, l'audizione dello studente, la proporzionalità e le competenze restano disciplinate dai regolamenti scolastici vigenti. Prima della diffusione istituzionale è opportuna la validazione dei contenuti da parte della dirigenza.
